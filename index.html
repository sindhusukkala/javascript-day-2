JavaScript Loop Comparison Guide

Summary Table

Loop Type Best Use Shines When Potential Pitfalls
for Iterating a fixed number of times Index-based iteration Can lead to off-by-one errors, infinite loops
while Looping with unknown iteration count Waiting for condition Infinite loop risk if condition never false
do...while Must run at least once Input validation Runs once even if condition is false
for...in Iterating over object keys Works on objects Includes inherited keys, avoid for arrays
for...of Iterating over iterables Arrays, strings, maps Does not work with plain objects

Code Examples

for loop: 
for (let i = 0; i < 5; i++) {
  console.log("Count:", i);
}
while loop: 
let x = 0;
while (x < 5) {
  console.log("x is", x);
  x++;
}
do...while loop: 
let y = 0;
do {
  console.log("y is", y);
  y++;
} while (y < 5);
for...in loop (for objects): 
const person = { name: "Alice", age: 25 };
for (let key in person) {
  console.log(key, ":", person[key]);
}
for...of loop (for arrays, strings): 
const fruits = ["X", "Y", "Z"];
for (let fruit of fruits) {
  console.log(fruit);
}
